# Шрифти

`src/main/res/font/` — статичні TTF, зібрані з пакетів @fontsource (ті самі шрифти, що й у вебі):
латиниця + кирилиця об'єднані через fontTools, Nunito — інстанси 400/600/700/800/900 зі змінного шрифту.

|---|---|---|---|

| `russo_one.ttf` | Russo One | Jovanny Lemonad | SIL Open Font License 1.1 |
| `pixelify_*.ttf` | Pixelify Sans | Stefie Justprince | SIL Open Font License 1.1 |
