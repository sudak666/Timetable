# Розклад уроків

`index.html` — сторінка, `config.json` — курс оцінок і бонуси.

## Змінити курс
`rates`: оцінка → гривні (мінус = штраф). Діє на нові підтвердження; вже підтверджені оцінки зберігають свою суму.

## Нарахувати бонус / штраф
Додай рядок у `bonuses`:
```json
{ "date": "2026-10-01", "amount": 200, "note": "Перемога на олімпіаді 🏅" }
```
`amount` може бути від'ємним. Бонус потрапляє в підсумки дня/тижня/місяця за `date` і в баланс.
